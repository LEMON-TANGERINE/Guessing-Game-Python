# Guessing Game

¡Bienvenido al **Guessing Game**! 🎉  
Este es un mini juego en Python donde el jugador tiene que adivinar un número secreto generado por la computadora.

## Cómo jugar

1. Ejecuta el archivo `guessing_game.py` en tu terminal o editor de Python.
2. La computadora elegirá un número al azar entre 1 y 100.
3. Introduce tu intento y presiona Enter.
4. La computadora te dirá si tu intento es **demasiado alto** o **demasiado bajo**.
5. Sigue intentando hasta adivinar el número correcto.
6. ¡Al acertar, recibirás una felicitación y el número de intentos realizados!

python guessing_game.py
